# SpeakSafe

A responsive prototype website for **SpeakSafe**, our CA2 solution for *Problem Solving with Creative & Computational Thinking* (Singapore Polytechnic, DMRO/1B/02, Group 4).

**Problem statement:** How can we safeguard employees in Singapore against workplace bullying and the misuse of authority?

SpeakSafe is an independent, anonymous reporting system. Reports go to a neutral third party instead of the employee's boss or HR. There are fixed triage rules (48-hour urgent investigations, an audit after 3+ reports on one supervisor) and anti-retaliation protection with no time limit.

## What's on the site

- The problem, with sources
- The seven parts of the solution
- The 8-step algorithm and the flowchart
- A demo report form that issues a Case Reference Code
- A demo case tracker
- An FAQ

The site is a demonstration only. Nothing is sent to a server; demo cases are kept in the visitor's own browser.

## View it

Open `index.html` in a browser, or publish it with GitHub Pages:

1. Go to the repo's **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the `main` branch and the `/ (root)` folder, then **Save**.
4. After about a minute the site is live at `https://mrp1z2a.github.io/PSCCT/`.
